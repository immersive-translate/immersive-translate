# 沉浸式翻译 · Immersive Translate

让外文阅读更轻松的双语翻译工具。

沉浸式翻译在网页中同时呈现原文与译文，保留阅读上下文，帮助你阅读外文资讯、论文和学习资料。支持网页、PDF、电子书、视频字幕、图片与漫画翻译，并可按需选择多种翻译服务。

[**安装沉浸式翻译**](https://immersivetranslate.com/docs/installation/) · [使用文档](https://immersivetranslate.com/docs/) · [版本下载](https://github.com/immersive-translate/immersive-translate/releases) · [问题反馈](https://github.com/immersive-translate/immersive-translate/issues)

## 主要功能

- **网页双语翻译**：支持整页、划词、鼠标悬停和输入框翻译。
- **文档翻译**：支持 PDF、EPUB、TXT、HTML 和字幕文件，PDF 翻译可保留原有排版，方便对照阅读。
- **视频与会议字幕**：支持在线视频双语字幕及部分会议平台的字幕翻译。
- **图片与漫画翻译**：支持网页图片、本地图片及部分漫画网站。
- **多种翻译服务**：按需选择翻译引擎或接入自定义 API；部分服务支持术语库、领域设置和上下文翻译。

## 隐私与数据安全

翻译请求通过加密通道传输。在适用的官方翻译服务范围内，翻译内容不用于 AI 模型训练。内容处理与保留规则因功能及所选服务而异，涉及临时文件保留的功能会说明处理用途与删除规则。

关于安全认证、数据处理方式，以及第三方服务和自定义 API 的适用范围，请参阅[信任中心](https://immersivetranslate.com/zh-Hans/security/)与[隐私政策](https://immersivetranslate.com/zh-Hans/docs/PRIVACY/)。

## 开始使用

[安装扩展](https://immersivetranslate.com/docs/installation/)，打开需要阅读的网页，点击翻译即可查看双语内容。不同翻译服务与进阶功能的可用范围，以产品内说明为准。

使用帮助：[查看文档](https://immersivetranslate.com/docs/)

## 关于这个仓库

本仓库用于发布沉浸式翻译扩展的 [Release 版本](https://github.com/immersive-translate/immersive-translate/releases)，并通过 [GitHub Issues](https://github.com/immersive-translate/immersive-translate/issues) 收集和跟进用户反馈。

[沉浸式翻译](https://immersivetranslate.com/)并非开源软件，本仓库**不包含沉浸式翻译的源代码**。旧版的[沉浸式翻译开源项目](https://github.com/immersive-translate/old-immersive-translate)已于 2023 年 1 月 17 日归档。
