# 官网首页隐私保护模块

按用户2026-09-29参考图，在原官网口碑区之前新增蓝底隐私保护模块。当前仓库不含官网源工程，本目录为本地接入预览，未发布。

## 运行

在仓库根目录运行：

```sh
python3 web/home/serve.py
```

打开 http://127.0.0.1:4318/home/#privacy-protection 。需要网络以加载官网公共资源和演示视频。不要使用普通静态文件服务器：官网原始脚本还会请求 `/_next/static/` 下的资源。

## 修复后的预览方式

先前静态化首页移除了官网脚本，造成首屏按钮、功能演示、角色切换和滚动内容不完整。现已恢复原始HTML、样式、脚本和资源路径；原站完成渲染后，仅插入新增模块。导航、角色切换、演示视频、口碑滚动由原站代码负责。

- `source/homepage.html`：2026-09-29获取的官网公开原始HTML。
- `index.html`：原始HTML只增加模块样式和接入脚本两行。
- `serve.py`：本地预览服务器，加载并缓存官网公共静态资源；不代理账号/API或转发登录凭证。
- `preview.js`：原站渲染后插入模块，其他页面的站内链接指向官网。
- `check_preview.py`：回归检查，保证原始脚本、结构、内联样式及资源路径完整保留。旧实现验证失败，修复后通过。

预览运行原官网客户端代码，因此原站活动提示、联网行为及外部服务状态仍会出现。这里不提供完整翻译应用或登录服务；其他产品链接进入官网。

## 接入源工程

1. 将 `privacy-section.html` 放在首页口碑 section 前。
2. 加载 `privacy-section.css`；样式限定在 `.home-privacy` 内。
3. 复制 `assets/` 下三张PNG和 `chevron-right.svg`，调整图片路径。
4. 正式源工程直接渲染模块，不需要 `serve.py` 或 `preview.js`。

新增模块无需JavaScript；桌面三列、700px以下单列。按钮进入官网安全页；口碑标题保留当前官网3000万口径。三张插画使用内置ImageGen重建，各prompt在素材同目录。
