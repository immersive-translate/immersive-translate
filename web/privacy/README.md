# 安全页与上传隐私入口

交付模式：代码。基于用户指定的[原安全页](https://immersivetranslate.com/zh-Hans/security/)（2026-09-29 获取）实现局部修改。当前仓库是插件发布仓库，不含官网或文件上传应用的源代码；本目录为独立本地实现与接入片段，尚未发布或接入线上应用。

## 本地预览

在本目录运行，无需安装或构建：

```sh
python3 -m http.server 4317 --bind 127.0.0.1
```

- 安全页：http://127.0.0.1:4317/
- 上传入口位置预览：http://127.0.0.1:4317/upload-preview.html

上传预览中的原上传框仅用于展示位置，未接入上传或翻译服务；新增的隐私链接可正常点击，按用户要求在当前标签页进入线上安全页。

## 已实现

- 头部副标题替换为用户指定的两段原文，文字居中并平衡换行。
- 合规与认证按参考图改为 ISO 27001、ISO 27701、GDPR、APPI、SSL/TLS 五卡；桌面 3+2、平板 2+2+1、手机单列。

## 接入实际源码

1. `hero-copy.html`：原首屏副标题的替换内容。
2. `compliance.html`：合规模块及装饰 SVG 图标定义；样式见 `page.css` 中 `.security-compliance` 与 `.svg-definitions`。
3. `upload-privacy.html`：插入在原上传框闭合标签之后，置于边框外，保留原上传处理逻辑；加载 `upload-privacy.css`。单个文件与批量翻译若共用框体，应把链接放在公共框体外。
4. `page.js` 仅供这个静态预览恢复原站交互；集成时保留项目原有导航和选项卡逻辑，无需替换为此脚本。

`index.html` 使用原站公开渲染的 HTML 和样式，不包含账号请求、分析脚本或 Next.js hydration。所有展示资源已保存在 `assets/original/`；来源列表在 `assets/original/sources.json`。导航外链仍指向原网站。
