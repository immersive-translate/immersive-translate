数据安全架构

从文件上传到翻译返回，每一步都经过严格的安全设计，确保您的数据在整个流程中受到全方位保护。

本地优先原则

Local-First Processing

在本地完成排版逻辑与结构分析，仅将需要翻译的原文发送至翻译接口，最大限度减少数据外传。

零存储策略

Zero-Retention Policy

我们不存储用户的任何翻译日志（Log）。所有翻译内容在实时返回后立即从内存中销毁，不留任何痕迹。

AES-256 加密传输

End-to-End Encryption

数据传输全程采用 AES-256 加密标准与 TLS 1.3 协议，确保从用户浏览器到翻译引擎的每一个字节都受到保护。

自定义 Key 支持

Bring Your Own API Key

Pro 用户可配置私有 API Key，数据流向完全透明，翻译请求直达您选择的服务商，无中间存储。

我们的承诺

隐私不是附加功能，而是产品的基石。我们以最严格的标准守护您的每一份数据。

绝不买卖数据

我们不通过广告或数据变现，订阅费是我们的唯一收入。

最小化收集

仅收集必要的功能性数据（如账户状态、翻译字符统计）。

透明化控制

每一项权限申请（如“读取所有网站”）都有详细的使用场景说明。

查看隐私政策

安全保障体系

安全通信

沉浸式翻译使用加密传输协议（HTTPS），通过 SSL/TLS 协议对客户端与服务器之间所有数据在传输过程中均以加密方式进行，确保数据在传输过程中无法被第三方截获、读取或篡改。

身份鉴别与访问控制

沉浸式翻译通过账号登录机制对用户身份进行识别，并基于最小权限原则进行访问管理，限制非必要的系统访问，降低未经授权使用带来的风险。

安全计算环境

沉浸式翻译的服务器运行环境经过安全加固，定期进行系统更新与漏洞修复；通过日志记录、异常监测与告警机制，对系统运行状态进行持续监控，在发现异常情况时及时采取应对措施，保障系统与数据的安全稳定运行。

数据备份与灾难恢复

我们建立了数据备份与恢复机制，对关键数据进行定期备份，并制定灾难恢复预案，在突发情况下最大程度降低数据丢失风险，保障服务的持续可用性与您的使用权益。

安全管理机构

我们设立了专门的信息安全管理团队，明确安全管理责任，负责信息安全相关工作的规划、执行与持续改进，确保数据保护措施能够长期、稳定地落实。

安全管理制度

我们已制定并严格执行涵盖信息安全管理、权限控制与应急响应的全套安全规范，通过制度约束与流程管理，防止数据被未经授权访问、使用或泄露，全方位保障您的数据安全与系统可靠。

安全建设管理

沉浸式翻译在功能设计与版本迭代过程中，将安全要求纳入产品开发流程，在新增功能上线或系统发生变更前，都会进行必要的安全评估与确认，持续降低潜在安全风险。

信息安全意识

我们重视内部员工的信息安全意识，通过定期开展内部培训与宣导，提升员工对信息安全、数据保护与合规要求的理解与重视程度，并在日常工作中落实相应规范与约束措施，减少因人为操作不当而带来的安全风险。
